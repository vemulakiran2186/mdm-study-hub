A modern, responsive, and highly optimized web application built for **Medha Dakshina Murthy Study Hub**. The platform is designed to showcase the institute's academic programs (6th-10th, Intermediate, and Degree levels), unique teaching methodologies (Code Learning, Revision-Ready), and its emphasis on spiritual discipline.

## ✨ Features

- **Modern UI/UX:** Clean, professional light theme utilizing glassmorphism and smooth micro-animations.
- **Responsive Design:** Fully mobile-optimized layout using CSS Grid and Flexbox.
- **Functional Contact Form:** Direct email inquiry integration powered by [Web3Forms](https://web3forms.com/), alongside quick-action WhatsApp and Call buttons.
- **Optimized Performance:** Fast load times achieved through Vite's build process and Tailwind v4.

## 🛠️ Technology Stack

- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Form Handling:** [Web3Forms API](https://web3forms.com/)
- **Hosting & Deployment:** [Vercel](https://vercel.com)

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/medha-study-hub.git
   cd medha-study-hub
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment:**
   If you wish to test the contact form, ensure you update the Web3Forms `access_key` in `src/components/Contact.jsx` with your own key.

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   *The application will be available at `http://localhost:5173/`*

### Building for Production

To create a production-ready build:
```bash
npm run build
```
This will generate optimized static files in the `dist/` directory.
